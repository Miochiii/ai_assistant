# Watch 手动模块选择

按用户要求在已有 Orb 陪伴设置中增加两个独立模块的手动选择，不融合引擎。

- 版本：Orb 开发版 0.2.1-mio-dev.11。
- 设置路径：DSH 设置 → Orb 开发版 · Mio → Watch 陪伴设置 → 陪伴模块。
- `mode: screen | video` 与原间隔参数一起保存到 runtime/companion/settings.json。没有 mode 的旧文件默认 screen。
- 屏幕模式显示原采样、看图、发言间隔；视频模式展示原插件设置入口说明，隐藏屏幕专用参数并保留其值。
- 保存不启动模块。屏幕模式修改设置仍暂停当前屏幕陪伴；切换到视频会结束屏幕采样，释放消息拦截。
- 视频模式的“开始陪伴”“继续陪伴”“停止陪伴”“暂停陪伴”“陪伴状态”等显式控制转交 DSH 原生代理调用 watch_together。暂停与停止均使用原插件 stopLoop，恢复重新跟随播放位置。
- 正常视频聊天走原生会话，不经过独立看屏模型。视频插件未加载时给出重启提示，不静默回退屏幕模式。
- 执行中的任务阻止模块切换，请先停止当前陪伴或任务。两个模块各自管理运行状态；不存在自动场景切换。

验证：host/client 语法检查通过；17 项陪伴及流式请求测试通过，包括实际 host 方法的视频入口、插话状态/停止、释放旧拦截、插件缺失、运行中禁止切换、切回屏幕和旧配置兼容。首次默认测试 runner 被沙箱禁止创建子进程，改用 --test-isolation=none 后通过。尚未在重启后的真实设置页面点击验收，也未调用付费视频陪看。

更新直接落在已接入的 E 盘开发包与外部 host 模块中。重启 DSH 后加载；watch_together 上游源码和记忆模块未改。
