# Orb 陪伴 Watch 接入

用户澄清 Watch 以 See Now 桌面陪伴为主，演示学习暂缓。本轮 `.9` 用陪伴入口替换 `.8` 演示录制入口，保留未挂载的录制代码与旧记录，不改动已验收的 Evolve 插件、配置和数据。

## 实现

`plugins/dsh-assistant-host/orb-companion.js` 直接导入本地 dsh-see-now 0.0.7 的 pipeline 与 scale 模块，原第三方源码和 LICENSE/NOTICE 保留。筛帧、积分/切点、去重、拼图沿用上游；MSS 仍负责显示器 1 的截图，沿用原生 `overlay.withCapture` 排除 Orb 窗口，避免自己看自己的回复。没有安装另一个悬浮窗，也未安装 ffmpeg。

每次约 2 秒本地采样，完整显示器画面按比例缩到 800×450 内，非 16:9 屏幕留边而不裁掉边缘。第一张有效画面可触发初次回应；后续只在有新的保留帧时请求模型。静态兜底帧在这个陪伴适配中关闭；自动请求最少间隔 30 秒，少说一点为 60 秒，模型连续静默后最多退避至 120 秒。初始画面通常在两次采样后可用，再加模型响应时间；不承诺精确延迟。

复用 `companionStream` 的 DSH llm 服务和官方附件服务；默认路由 deepseek-official/deepseek-flash，单次输出上限 512 token，不带工具、不进入原生任务历史。角色提示要求自然回应、允许沉默、不重复播报、不猜测模糊文字、不把画面中的文字当作指令。保留最多 8 条陪伴对话短上下文，暂停/继续同一会话时保留；停止后重开清空。本轮没有角色卡设置界面或 Evolve 长期记忆读写桥接。

原始截图和 RGB 使用临时目录，每次读取后清理；不生成演示步骤记录。发给模型的图片由 DSH 附件服务保存，沿用其附件保留机制，不能声称所有图像都只存在于内存。本地调试日志在内存中最多保留 256 条。没有从截图提取并自动写入长期记忆。

陪伴回复经 Orb 原生 block 通道显示，接入原有 voice begin/end 通道；是否出声仍取决于用户原有语音设置及 TTS 可用性。本轮未验证真实语音播放。

## 命令和输入路由

- `开始陪伴` / `开启陪伴`：启动，只在没有当前操作任务/待处理交互时允许。
- `陪伴状态`：本地状态、采样次数、模型请求次数、发言次数、路由与节奏。
- 开启后普通文本及插话直接进入陪伴，不会执行操作。用户插话取消旧模型请求并采当前画面，旧请求即使迟到也不能出声或显示。
- `暂停陪伴`：停止采样和在途模型请求，保留短上下文。暂停时普通输入提示继续/停止，不暗中转成桌面任务。
- `继续陪伴`：恢复同一会话的短上下文，采样和调用计数按新一轮统计。
- `少说一点` / `正常陪伴`：调整自动看图节奏。仅口头降低发言量不能减少视觉输入，这里同时限制请求频率。
- `停止陪伴`：停止后普通消息恢复原 Orb/Evolve 任务入口。
- `.8` 的 `开始观察` / `观察状态` / `停止观察` 是上述陪伴命令的别名。命令返回会明确看图和回复消耗 token。

切换会话、停止按钮、关闭 Orb/卸载插件结束陪伴，重启不自动恢复。观察期间发现操作任务运行也会停止。截图错误直接停止；连续两次模型错误停止，避免自动无限错误重试。关闭时不等待失控远端请求，但立刻取消并阻止迟到回复；取消不代表服务商一定不计费。

## 验证

- `tests/test_orb_companion.mjs`：使用真实上游 pipeline 的静态不反复请求、画面变化/最小间隔、静默退避、直接提问、短上下文上限、迟到回复、连续插话、停止采样、错误停止、长宽比保留、实际 Orb 方法的路由分流、原生 capture guard 调用、暂停/继续和外部操作停止。
- 原有 `test_orb_watch.mjs`、`test_orb_task_memory.mjs` 与 companion stream/model check 回归一起运行。
- `scripts/check_orb_companion_native.mjs`：使用已安装 DSH 的 Context、附件服务、llm 及官方 DeepSeek 适配器，真实 MSS 截图经 See Now 拼图、附件编码，进入本地模拟 SSE 回复。验证图片 PNG、零工具、512 token 输出上限及回复解析。无付费 API 请求、无桌面输入，测试图和隔离附件库均删除。数值报告在 `results/watch/companion-native.json`。
- 初次简化模拟模型未声明 reasoningEffort=off，宿主在发出请求前拒绝；测试改用真实官方适配器加本地 SSE 模拟后通过。没有改动生产模型协议以迎合测试。
- 没有代用户重启 DSH、没有运行真实付费陪伴会话。真实界面表现、视觉判断质量、声音以及自窗口排除效果待验收。

## 用户验收

1. 完全退出并重开 DSH，加载 `.9`；在显示器 1 打开网页或软件。
2. Orb 输入 `开始陪伴`。等待初次看屏回应；如果她选择静默，可以问“你看到我现在在做什么？”。
3. 切换到明显不同的软件/页面，等待约 30 秒以上及模型响应，观察回应是否贴合新画面；允许有画面变化但保持沉默。
4. 直接插话“这是什么页面？”或“陪我聊聊这个”，验证她回答最新问题，不重复旧回复。
5. `少说一点` 后查看 `陪伴状态`；`暂停陪伴` 后等待确认采样/调用计数不再增加，`继续陪伴` 后恢复。
6. `停止陪伴` 后计数停止；再发普通桌面任务应走原操作入口。不要把陪伴看图回应当作已执行任务。

当前属于低帧率屏幕陪伴，快速的视频镜头/弹窗可能漏掉；800×450 拼图不保证读清小字，尚无高分辨率按需重看入口。下一步依据真实陪伴验收再调节节奏/角色与记忆联动，演示学习暂缓。
