## RH02 实现

### 状态与任务

`ResidentHost` 分离记录：

- `assistant`: starting/ready/closing/closed/fault
- `mode`: companion/coach/standby
- `observation`: stopped/starting/running/paused/fault（本阶段只做状态，不采集）
- `task`: 单活动任务，含 task_id/step_index/step_id/status
- `model_request`: 单活动请求（测试使用离线模型）

已验证：

- 启动默认 standby，无任务
- 聊天不创建任务、不破坏任务 A
- 任务 A → 闲聊 → 结束 A → 任务 B
- 任务切换后 A 的迟到回复被丢弃
- 暂停观察会取消待处理请求并进入 standby
- close 幂等，释放实例锁
- 重复 event ID 只处理一次
- 旧 epoch 事件被拒绝
- 连续两条聊天各收到 ack 和回复

### 文件通道

`UiChannel` 提供：

- `inbox/`：每个事件独立文件，原子写入
- `acks/`：accepted / handled / rejected
- `outbox/`：不可覆盖消息
- `state.json`：只由 Host 写入，revision 不回退
- `instance.json` / `instance.lock` / `heartbeat.json`
- event ID 去重、单实例锁、大小上限、保留上限

语义是 **at-least-once + ID 去重**，不是跨崩溃 exactly-once。未处理崩溃恢复。

### 插件入口

`index.js` 只注册 `/assistant-check` 人类命令：

- 运行 `runOfflineCheck`
- 不启动常驻 Host
- 不截图
- 不调用模型/API
- 不发送桌面输入

插件未安装；`cordis.patch.yml` 已准备好，待 RH03 前再决定是否加载。
