# 模块一：记忆

## 1.1 它是什么

`dsh-memory-evolve`（本地 vendor，0.1.0，MIT）是一个 **DSH 插件**：负责分层记忆、自我进化（经验沉淀 + 技能自动创建）、技能管理、待办、临时便签、提示词管理、会话广播/搜索/编排、渠道通知、跨设备同步。

对模型暴露三个工具：`memory`（读写记忆）、`skill_manage`（技能）、`dtodo`（待办）。

## 1.2 五条记忆轨

| 轨 | 存什么 | 作用域 | 注入 |
|---|---|---|---|
| `memory` | 全局事实（环境、工具链、机器级约定） | 所有会话 | 每轮注入 |
| `user` | 用户档案（偏好、习惯） | 所有会话 | 每轮注入 |
| `project` | 本项目约定/进展 | **按 cwd 哈希隔离** | 本项目会话注入 |
| `key` | 项目关键记忆 | 本项目（可按 git 分支过滤） | 摘要注入 + `expand` 拉全文 |
| `daily` | 今日日志 | 按日期 | 按需读 |

落盘（本项目）：`runtime/memory-evolve/{MEMORY.md, USER.md, projects/<hash>/…, daily/…}`。

## 1.3 注入是怎么发生的

每轮生成之前，插件把各轨内容拼成系统提示里的固定段落（"长期记忆""用户档案"）。所以**写进记忆的内容 = 模型下次一定会看到**，不依赖它主动检索。这一点决定了我们的用法。

## 1.4 技能系统（"流程复用"真正的载体）

- 一个技能 = 一个目录 + `SKILL.md`，frontmatter 里 `name` + `description`；
- 模型只在目录里看到**名字和一句描述**，需要时才加载全文（省 token）；
- 来源分层：`user-dsh` / `user-agents` / `custom` / `bundled` / `project-dsh` / `project-agents`；
- 禁用 = 改写 frontmatter `disable-model-invocation: true`（模型看不到、`skill` 工具拒绝加载）；
- **模型自建技能走"待确认队列"**（`pending-skills/`），要用户在面板采纳才进库。

## 1.5 我们做过的三件事

1. **摸清作用域坑**：机器级事实写进 `target=memory`（全局），不要写 `project`。
   事故：启动配方写进了 project 轨，Orb 的 cwd 是 `dsh_orb_work`，两个 project 互不可见 → "查不到任何记忆"。
2. **固化启动配方**：全局轨 6 条（六个应用启动命令、VPN 连接流程、端口分配、UTF-8 写文件坑、hf-mirror 下载、GitHub 直连失败）。
3. **建技能 `launch-windows-apps`**：把启动姿势（`explorer.exe` 脱离作业）、六应用表、VPN 前置、验收方法写进 SKILL.md；用户采纳后进技能库。

## 1.6 怎么验证它真的生效

问 Orb 四个问题（都实测通过）：

1. "我平时用什么 IDE？" → PyCharm；
2. "启动微信用什么命令？为什么不能直接 Start-Process？" → 答 `explorer.exe` + 作业连坐；
3. "QQ 现在开着，我让你再启动一次你怎么做？" → 先 `Get-Process` 查；
4. "帮我把 codex 打开" → 先 iKuuuVPN 连接（google 200）→ 再启动 ChatGPT。

## 1.7 现状与坑

- 全局轨 6 条；`~/.dsh/config.yaml` 不存在 → 插件全默认配置；
- RAG 的 MCP（`http://127.0.0.1:8000/mcp`）当前 **disconnected**：服务未启动（端口空着，非冲突），用户决定后期再启用；
- `project` 轨永远只对本 cwd 可见 —— 跨会话该知道的东西，只能进全局轨或技能。

# 模块二：操作（桌面远控）

## 2.1 目标与分工

用户在外面用手机经 UU 远控电脑，"点开始菜单磁贴、找输入框"成本极高。目标：**一句文字 → Orb 自己完成**。

分工原则（用户拍板）：

- **壳层操作用命令**（启动程序、开项目、跑脚本）—— 省 token、省截图；
- **GUI 点击只留给必须在窗口内完成的**（菜单、按钮、文件树、对话框）。

## 2.2 工具面

`dsh_orb_full_orig/dist/computer-use`（DSH 官方 computer-use 的 Orb 分支），工具：`click` / `type_text` / `hotkey` / `scroll` / `drag` / `open_app` / `list_screens` 等，动作走同一套执行与取消流程。

## 2.3 坐标链（最容易出错的地方）

```
模型给 [x, y]（0–1000，所附窗口截图的空间）
   ↓ coordinateModeOf(session)  —— 两种模式
   ├ millifraction（默认）：requireNormalizedPosition 校验 0–1000 直接用
   └ pixel：modelPositionToHid(position, mode, 最近截图栅格) → 折回 0–1000
   ↓ mapNormalizedToGlobal(position, screen)
   x = bounds.x + (x/1000) × bounds.width      ← 已修：夹到 width-1
   ↓ pointOf / roundedPoint 取整
   ↓ SetCursorPos + mouse_event（或 SendInput）
```

**修过的 bug**：`[1000,1000]` 被算成 `bounds + 1.0 × 宽`，落到窗口外一格 —— 贴边的小控件（关闭按钮、行尾图标）会点到隔壁窗口。现在两处 `mapFractionToGlobal` 都夹到最后一个像素（`Math.min(fx*width, width-1)`），中间坐标完全不变。

## 2.4 观察范围：是"窗口"，不是"全屏"

`selectWindowsObservation()`：取前台窗口作为 owner，把**同进程的弹窗/菜单**（transient）并进 bounds，物理像素 + `scale = monitorDpi/96`。

两个关键副作用：

- `SHELL_CLASSES`（开始菜单、任务栏弹出层）**不当 owner** —— 所以开始菜单打开时它会退到"下一个合格窗口"，出现过"只框到左半边、右半边截不到"的现象（用户决定不修：启动已走命令）；
- 观察范围就是坐标映射的 `bounds` —— **窗口图与显示器 bounds 一旦混用，所有点整体偏**。

## 2.5 截图与"挡自己"

点击/截图前要发 `overlay-capture` 让 helper 把 Orb 自己的悬浮球/面板挡出画面：

```
agent → helper: overlay-capture(active:true)   等 ack（预算 1000ms）
       → helper: cloak.begin → setContentProtection(true)
       → 截图
       → overlay-capture(active:false) → 截图结束
```

这个通道与陪看共用，所以**陪看与"代操作"互斥**：操作任务一开始，陪伴会主动停。

## 2.6 启动配方（实测过的，已进记忆/技能）

统一姿势：`Start-Process explorer.exe -ArgumentList '"<exe>"'`（**直接启会被 pwsh 作业连坐杀掉**）。

| 应用 | 入口 |
|---|---|
| iKuuuVPN | `E:\vpn\ikuuu_vpn\iKuuuVPN.exe` |
| 微信 | `D:\Weixin\Weixin.exe` |
| PyCharm | `E:\pycharm\PyCharm 2025.1.1.1\bin\pycharm64.exe` |
| VS Code | `E:\vscode\Microsoft VS Code\Code.exe` |
| QQ | `shell:AppsFolder\QQ`（AppID 别名） |
| ChatGPT（=codex） | `shell:AppsFolder\OpenAI.Codex_2p2nqsd0c76g0!App` |

需要 VPN 的（ChatGPT）：iKuuuVPN 起来后点**窗口 55% 宽、30% 高**处的圆形按钮，判定"已连接"= 界面出现计时器 + `https://www.google.com` 返回 200（只看进程不算）。

## 2.7 诊断接口（临时，开关式）

目的：分得清"模型找错目标"还是"坐标映射算错"。

- **开关**：`~/.dsh/location-test.json`（`{"enabled":true,"dir":"…/log/location_test"}`），删掉即关闭；
- **钩子**：`dist/computer-use/location-test.js`，只在 click 执行体里被调用；开关关闭时不读盘、不截图、不产生文件；
- **落盘**：`log/location_test/events.jsonl`（一行一次）+ `shots/<id>.png`（点击前截图）+ `annotated/`；
- **每条记**：坐标模式、模型原始点、换算后 0–1000、全局点、bounds、scale、窗口 id/app、截图尺寸、是否在范围内；
- **看图**：`tools/location-test/annotate.py` 把点击点画蓝十字、图像中心画红圈。

判读表：

| 现象 | 归类 |
|---|---|
| 蓝十字压在目标上但没反应 | 执行后状态变 |
| 蓝十字整体平移/缩放 | 坐标映射错 |
| 蓝十字在范围内但目标在别处 | 模型找错目标 |
| 目标根本不在截图里 | 目标不可见（需先滚动/展开） |

## 2.8 决策与未验证

- **不做**候选区域裁剪、不接 GUI 定位器、暂不加更重的诊断层：用户判断"模型多看两眼就能点对"；
- **触发条件**：出现 ≥2 个同类误点再立项（有 20~30 条基线数据再看）；
- **未验证**：PyCharm 带项目路径启动、QQ 已登录时重复启动、窗口内多步组合操作、手机真机全链路。

# 模块三：陪看

## 3.1 两条通道

| 通道 | 做什么 | 入口 |
|---|---|---|
| **屏幕陪看** | 定时截屏 → 模型判断"值不值得说一句" → 说 | `orb-companion.js` + `capture_once.py --monitor 1` |
| **视频陪看** | 按播放进度出分镜/字幕，陪用户看视频 | `watch_together` 插件 + 我们接的 ASR |

## 3.2 屏幕陪看：节奏与协议

- 采样：每 2 秒截一次显示器（能量管线保留"有变化"的帧）；
- 发言节奏：自动看图 ≥10 秒、主动发言 ≥10 秒、最小间隔 30 秒、可"少说一点"降频；
- 模型调用：`deepseek-flash`，`maxTokens 192`；
- 输出协议：只允许 JSON `{"speak": true/false, "text": "...", "reason": "..."}`，解析失败即丢弃（不猜）；
- 长度：`trimToSentence(text, 30)` —— 按最后一个完整句截到 30 字以内。

## 3.3 视频陪看：ASR 接入

- 选型：**sherpa-onnx + SenseVoiceSmall int8**（CPU、无 torch），服务 `tools/asr/sensevoice_server.py`；
- 接口：OpenAI 兼容 `/v1/audio/transcriptions`，另有 `/health`、`/v1/models`、`/shutdown`；
- 关键防护：能量 VAD 分段（≥0.45 秒）、峰值门限、整段"像不像语音"判定 —— 解决静音段幻觉（"喂。""Yeah. The."）；
- 配置：`~/.dsh/asr.json`（`baseUrl` / `model` / `language` / `manage{start,waitMs,idleMs,healthPath}`），**端口 8100**（8000 让给 RAG）；
- 实测：12 秒音频 → 0.36 秒（33×）、120 秒 → 4.4 秒、冷启动 2.4 秒、RSS ≈330MB、空闲 60 秒自退；
- 契约：`tools/asr/check_asr_contract.mjs` 6 项（探活/转写/响应形状/静音/坏音频/管道 WAV）全过。

## 3.4 体验层：球、面板、两行浮条

- 悬浮球与面板是**同一个 BrowserWindow**（收起 96×96，展开 344×444）；
- 屏幕陪看时**不自动弹面板**（会挡画面），改为球旁边一条**两行浮条**：
  - 第一行状态 `看屏中 · 采样 N · 发言 M`（暂停变黄点）；
  - 第二行最近一句，**每句至少留 5 秒**，新句从下往上替换；
  - 360×92、磨砂（blur 20 + 半透明 + 发丝边）、`click-through`、不抢焦点、挂球**下方**、**右对齐**球右边；
  - 数据走 `~/.dsh/dsh-orb/companion-ticker.json`，helper 每 700ms 轮询（不新增进程间协议）。

## 3.5 角色卡与人设

- 角色卡：名字 / 人设 / 指导单独人设 / 陪伴字数上限（默认 30）；
- 注入顺序：**角色卡 → 一句边界 → 模块原有硬约束**（格式、无工具、不编造不能被卡改写）；
- 人设统一：装了 `dsh-persona-dafeiyu`（全局人设）后，Orb 的陪伴/指导每 60 秒从它的 HTTP 桥抄当前人设；卡里人设留空 = 跟随全局（不叠"你的名字是…"，避免两个名字打架）；关掉就立即退回空，不沿用旧文本。

## 3.6 三个事故（都值得讲）

1. **每 2 秒闪一下**：截图前给悬浮球 `setContentProtection(true)`、截完关掉；Windows 上这个调用**每次重绘一帧**。→ 改成常驻保护 + "值没变就不调用"。
2. **悬浮球消失**：给**透明窗**设内容保护会让整扇窗不渲染。→ 球与面板退出 cloak，只在提示词里告诉模型"角落的小球是你自己"。
3. **`overlay ack timed out`**：浮条启动函数在 `let` 声明之前调用，触发 TDZ 抛错，导致 helper **后面的消息分发对象根本没返回**，截图请求没人 ack。→ 启动延后一拍 + try/catch。

## 3.7 状态面板

三态（开启/暂停/停止）+ 控制矩阵（球/面板/语音三种入口都能停）+ `requestId` 幂等 + `revision` 守卫（并发点击不会重复停/重复起）。

# 模块之间的咬合

```
记忆 ──提供"怎么启动/怎么连 VPN"──▶ 操作
操作 ──执行结果（pid/窗口标题/退出码）──▶ 回执（手机端三行看完）
陪看 ──观察数据只进上下文，不写记忆──▶ （用户明确要求：不能自动变成个人事实）
操作 ⇄ 陪看：共用 overlay capture/cloak 通道，因此互斥
```

三条纪律：

1. **机器级事实进全局记忆**，项目级进 project，流程进技能；
2. **启动走命令，窗口内才点**；
3. **看到的不等于事实**：陪看看到的屏幕内容不进记忆。

# 总结（3 分钟讲稿）

> 下面这段是给人讲的，建议照着念，括号里是节奏提示。

**（0:00–0:40 起因）**
我做的这套东西，解决的是同一件事的三个面：手机上打字成本太高。你在外面用远控软件连电脑，想打开个程序、跑个测试、看个视频，都得自己缩小屏幕找按钮。我就让电脑上的助手替我干：我发一句话，它自己动手。

**（0:40–1:20 记忆）**
第一个模块是记忆。它不是"存聊天记录"，而是分层的：全局的、用户的、项目的、每天的，各存各的，每轮对话自动注入到模型的提示词里。关键设计是**作用域**——我踩过一次坑：把启动配方写进了项目记忆，结果另一个工作目录里的助手完全看不到，它说"查不到任何记忆"。后来才明白项目记忆是按目录隔离的，机器级的事实必须写全局。
技能是另一层：一句话的描述给模型看，真要用时才加载全文，这样既省 token 又能复用流程。我把它做成一个 `launch-windows-apps` 技能，里面写着"启动必须绕 explorer，否则进程会被 shell 作业连坐杀掉"。

**（1:20–2:10 操作）**
第二个模块是操作。这里最容易被低估的是**坐标**。模型看到的是窗口截图，坐标是 0 到 1000 的比例；要变成真正的屏幕像素，中间要过三道换算。我修了一个一行的小 bug：模型被告知 1000 是右边缘，但换算时直接乘宽度，结果点到窗口外面一格——贴边的关闭按钮就会点到隔壁窗口。
还有个反直觉的点：它的"观察范围"不是整个屏幕，而是**前台窗口**。所以开始菜单那种系统界面会被跳过，只框到半个屏幕。我的处理不是去修它，而是让启动走命令行——能用命令做的事，就别让模型去点。
为了以后能查清"到底是它找错目标，还是坐标算错了"，我加了个临时诊断：开关是一个 json 文件，打开后每次点击记一行日志加一张点击前截图，再用脚本把点击点画成十字线。

**（2:10–3:00 陪看 + 收束）**
第三个模块是陪看。它每两秒截一次屏，只在新内容值得说时才说话，一句控制在 30 字以内，语气刻意做成"坐在旁边的朋友"而不是解说员；看视频那路我接了个本地语音识别，没有显卡也能跑，12 秒音频 0.36 秒出结果。
这中间修了三个很典型的坑：截图前要把自己的浮窗挡出画面，而在 Windows 上这个操作每次都会重绘一帧，于是画面每两秒闪一下；给透明窗做同样的保护，又会让整扇窗直接不显示；还有一次是变量声明顺序错了，抛了个异常，把整条消息处理链都带哑了，表现却是"截图超时"。
**一句话总结**：记忆负责"这台机器怎么用"，操作负责"把话变成动作"，陪看负责"看见但不乱说"；三者通过一条共享的截图通道咬合，而边界是——**能用命令的不用点击，看到的东西不写进记忆**。
