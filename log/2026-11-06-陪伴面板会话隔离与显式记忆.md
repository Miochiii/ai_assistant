# 陪伴面板的会话隔离与显式记忆

## 用户能做什么

在选定的 Harness 会话执行 `/assistant-open`。该会话决定工作区和任务转交目的地。面板有自己的短对话。想连续看屏时，在同一会话执行 `/assistant-model-watch`；结束观察用 `/assistant-model-stop`。关闭面板用 `/assistant-close`。

| 面板输入或事件 | 去向 | 带入下一轮的内容 |
| --- | --- | --- |
| 普通聊天，如“你刚才说的是什么意思？” | 独立文本模型请求 → 面板 | 最多四组已完成的面板问答，合计最多 8192 个 UTF-8 字节，以及最近发布到面板的一句观察（最多 320 个 JS 字符单元） |
| 门控放行一帧 | 独立视觉请求 → 解析发言或静默 | 当前一张图和可选的上次发言节选。仅发言进入面板，静默理由不进面板聊天 |
| `记住，以后教我一次只说一步` | 本地记忆服务 → 面板回执 | 原始用户事件和记忆在同一 SQLite 事务内提交，绑定用户、工作区、会话与事件 ID |
| `查记忆：一次只说一步` | 本地记忆库 → 面板 | 按关键词返回当前有效匹配，最多三条。查询和结果不追加到模型短历史 |
| `交给主会话：整理当前项目的待办` | 启动面板的 Harness 会话 | 仅转交冒号后的任务文本，走该会话原有权限 |

长期写入需要明确表达。普通对话、屏幕文字和模型生成的“记住”都不会自行成为长期记忆。新会话在相同用户和工作区下可以显式查询。未来若要让角色主动采纳已存偏好，需要另行定义用户同意、注入条数以及撤销后的生效范围。

## 接入位置与参考

Deep Agents 的 `third_party/sources/deepagents-main/libs/deepagents/deepagents/middleware/subagents.py` 为子任务重新构造 messages，仅传入指定任务描述。项目借鉴显式构造输入这一点。生产路径使用当前 Harness 的模型服务，不依赖 LangChain 或 Deep Agents。

- `plugins/dsh-assistant-host/companion-stream.js` 显式构造消息，为每次调用生成独立请求会话 ID，工具列表为空。异常、超时或非正常结束均不会回退到主会话。
- `model-check.js` 在同一时刻只允许一个在途观察。结果关联本次请求，停止后丢弃迟到结果。`panel-session.js` 按启动会话分隔文件通道；面板关闭时清空内存中的短对话。
- `panel-model.js` 是面板命令与模型聊天的分流处。`plugins/dsh-desktop-observe/memory.js` 从宿主会话取得工作区，复用已有记忆库。`src/assistant_memory/gateway.py` 的 `remember_panel_note` 在相同事件重投时返回同一条有效记录，遇到已更正或撤销的记录会拒绝旧事件。
- 更正和撤销继续走 Harness 人类命令。可用 `/memory recall {"route":"search","query":"一次只说一步"}` 找到 ID、kind 和 key，然后使用 `/memory revise` 或 `/memory revoke`。撤销会停止后续有效检索，清除源正文需走已有的 `/memory plan` 和 `/memory forget`。
- 隔离从新请求起生效。已有主会话历史仍可能包含旧版陪伴正文。想从干净的主上下文开始，可以在同一工作区新开会话启动面板。宿主附件、面板收发文件和本地诊断记录各有自己的存储，清空模型短历史只影响后续请求。

## 离线验收

本机 Harness 桌面包 0.2.2-rc.1。用原生 AgentLoop、LLM 适配器和附件服务，将网络传输替换为进程内 SSE。主会话先跑一轮，执行 20 次观察（10 次发言，10 次静默）并在面板追问，再跑一轮主会话。检查实际组装的请求体和会话事件：每次观察只含当前一张图，面板能引用最近发言，主会话保留自己的前文，陪伴内容产生的主会话事件数为零。测试没有读取真实桌面或凭据。

在项目目录的 PowerShell 中可复跑：

```powershell
$env:ELECTRON_RUN_AS_NODE='1'
try {
    & 'E:/dsh/DeepSeek Harness.exe' --expose-internals scripts/check_companion_isolation.mjs | Out-Host
} finally {
    Remove-Item Env:ELECTRON_RUN_AS_NODE
}
node --test --test-isolation=none tests/test_companion_memory.mjs
```

记忆用例使用项目测试目录的临时 SQLite 库及项目 Python，覆盖原话溯源、重复投递、同工作区跨会话、跨工作区隔离、更正与撤销。测试结束删除临时库。本轮相关测试共通过 108 个 Node 用例和 46 个 Python 用例，另通过原生 Harness 离线请求验收。真实账户、实时桌面效果和角色卡编辑器均不在本轮验收范围内。
