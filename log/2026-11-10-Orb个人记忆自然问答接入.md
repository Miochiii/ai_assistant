# Orb 个人记忆自然问答接入

用户已确认 `查记忆：星桥` 验收通过。本轮直接更新已接入 DSH 的 E 盘开发包至 `0.2.1-mio-dev.3`，不修改原 C 盘 Orb 包，不自动退出用户应用。

## 本轮行为

空闲时在指定 Orb 工作区输入“我用什么写 Python”“你还记得我喜欢哪个编辑器吗”等个人记忆问题，读取当前有效记忆，通过配置的 deepseek-official / deepseek-flash 独立请求回答。请求没有工具、历史或操作授权；正文和回答不写入原生 Orb 模型历史。显示前再次校验 SQLite 记忆版本与开关，变更后丢弃旧答案。

关闭自动记忆、下一次输入、停止和切换会话会取消或丢弃未完成回答。没有有效记忆会明确提示没有查到，不要求模型猜测。模型输出异常不展示为事实。建议类问题、动作请求、圈选请求和正在运行任务中的输入继续由原 Orb 路径处理。

首次检索显示等待提示。本地验证冷启动约 45 秒；真实模型回答还需额外时间。调用自然问答时存在有效召回才发起模型请求，会产生正常模型费用。本次开发验证使用模拟模型，没有付费请求。

## 验证证据

- 15 项 Node 回归测试通过：自然提问路由、动作及建议排除、无工具无历史请求、关闭及空记忆、异工作区、检索和生成期间失效、异常版本、取消、实际开发包 onPrompt 方法、原有本地控制与来源桥接。
- `scripts/check_orb_memory_recall.mjs` 使用临时 SQLite、真实 daily_ingest / 跨日 daily_commit、真实常驻检索和版本服务、开发包实际 onPrompt 方法及模拟 UI/模型，验证 PyCharm 偏好被检索、生成中撤销阻止旧答案、撤销后不再召回。报告 `results/memory/orb-natural-recall-smoke.json`。
- `scripts/check_orb_memory_service.mjs` 真实 CLI/临时 SQLite 回归原有显式写入、跨会话查询、关闭后拒绝采集、普通聊天路径通过。
- 开发包 host 语法检查通过。未用正式数据库作为测试夹具，尚未验收真实 DSH 重启后的自然问答。

## 用户验收

1. 完全退出并重新打开 DSH，继续使用“Orb 开发版 · Mio”。
2. 输入 `自动记忆状态`，应新增“个人记忆自动问答：开启”。关闭状态可输入 `开启自动记忆`。
3. 直接问 `我用什么写 Python`。若库内存在已经生效的 PyCharm 偏好，应回答 PyCharm。首次检索等待提示期间无需重复发送。
4. 若没有查到，可显式 `查记忆：PyCharm` 核查现有内容及其状态；不能因此声称自然问答已经通过。

仅候选、已撤销和过期条目不会自动使用。旧 `记住：` 便笺维持显式查询用途，所以“星桥”显式验收通过不代表该便笺已进入自动召回。新表达的偏好仍按跨日规则整理，不会当天强行提交。自然问答气泡目前仅在 UI transcript 中，不保证重开历史后重放，也不支持靠上一条本地回答理解“那它呢”等追问。

本轮没有开启所有桌面操作任务的记忆上下文注入。该部分仍需接入原生任务会话的失效与切换机制；不能将本轮个人记忆问答称为完整操作任务记忆接入。
