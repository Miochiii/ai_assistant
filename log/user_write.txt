# 任务：优化 Coach Overlay 的鲸鱼娘步骤气泡视觉

## 一、背景

当前项目里已经有一个可运行的 Coach Overlay PoC：

- 主流程代码：`tools/coach_overlay/coach_overlay.py`
- 鲸鱼素材：
  - `tools/coach_overlay/assets/DSniang02.png`
  - `tools/coach_overlay/assets/DSniang02-chroma.png`
- 音效：`tools/coach_overlay/assets/Ya1.mp3`
- 说明：`tools/coach_overlay/README.md`

现有能力：

- 全屏透明置顶 overlay
- 目标矩形、箭头、步骤文字
- 点击穿透
- 目标窗口失焦自动隐藏
- 多步骤 state
- 右下角鲸鱼娘 + 白色思考气泡
- 气泡内显示步骤，按钮“下一步”推进
- 点击后播放音效、做轻微弹跳
- 控制面板可暂停/关闭
- `--exclude-capture` 可让 mss 截图不包含 overlay

现在的视觉问题：

1. 气泡里的文字排版比较平，步骤层级不明显
2. “下一步”按钮像一个白色方框，和气泡融合得不好
3. 鲸鱼、气泡、目标矩形之间缺少统一的视觉语言
4. 长步骤文字会换行，行距/边距不够精致
5. 鲸鱼固定右下角，可能挡住目标区域
6. 动效只有简单淡入/弹跳，缺少“步骤切换”的节奏感
7. 关闭按钮和进度信息不够清晰

## 二、本次只做视觉优化

不要改变 Coach 的核心行为：

- 仍然是 display-only
- 不点击目标软件
- 不输入文字
- 不调用执行器
- 不改成 Host 闭环
- 不修改 `desktop_adapter`
- 不引入全局鼠标/键盘钩子

这次只优化：

- 鲸鱼气泡的视觉设计
- 气泡内文字/进度/按钮的排版
- 动效
- 鲸鱼位置避让
- 与主 overlay 矩形/箭头的视觉统一

## 三、设计方向

整体风格：

> 轻量、清爽、可信赖的桌面 Coach 提示，不是游戏悬浮窗，也不是广告挂件。

关键词：

- 深海蓝 + 白色气泡
- 细描边
- 柔和阴影
- 清晰的步骤层级
- 少量青色强调
- 鲸鱼娘是“助手”，不是视觉噪音

建议色板：

```text
深海军蓝   #0B1736
正文蓝     #35508F
次级蓝     #6B7FAE
强调青     #00E5FF
气泡白     #F7FBFF
浅蓝底     #DCEBFF
边框蓝     #8FA6D6
```

字体：

- Microsoft YaHei UI
- 步骤正文 15–16px 加粗
- 进度/辅助文字 10–11px
- 按钮 11–12px 加粗

## 四、具体视觉要求

### 1. 气泡内布局

气泡区域位于 `DSniang02` 的白色思考气泡内，约：

```text
图像坐标：x 34..416, y 4..250
显示窗口：520×520
```

请在气泡内建立清晰层级：

```text
┌────────────────────────────┐
│  STEP 1 / 3                │  ← 小号进度，青色/次级蓝
│                            │
│  点击“文件”菜单             │  ← 主步骤，最多两行
│                            │
│  [ 下一步  → ]              │  ← 主按钮，靠右下
└────────────────────────────┘
```

要求：

- 步骤正文最多两行
- 超长文字自动缩小字号或换行，不能溢出气泡
- 进度与正文之间留出明显间距
- 按钮不要贴气泡边缘
- 文字整体在气泡视觉中心，不要偏左

### 2. “下一步”按钮

当前按钮是独立小窗里的普通 `tk.Button`，看起来像白色方框。

请改成：

- 圆角矩形
- 白底/浅蓝底
- 深蓝文字
- 细边框
- 右侧一个 `→`
- 悬停时底色变浅蓝
- 按下时轻微下沉/缩小
- 点击区域至少 `136×36`

注意：按钮必须保留在**独立的不透明 Toplevel 小窗**里，不要放回透明鲸鱼窗。原因是透明鲸鱼窗的帧会变化，固定执行器的帧校验无法稳定点击；独立按钮窗是经过验证可点击的。

按钮窗可以继续使用 `Canvas` 自绘圆角，也可以保留原生 `tk.Button`，但视觉上必须像气泡内的一个整体控件，而不是外挂白框。

### 3. 关闭按钮

现在右上角的 `×` 不够明显。

建议：

- 放在鲸鱼窗右上角外侧
- 低对比度，不要抢“下一步”
- 悬停变红
- 点击关闭整个 overlay
- 不要放在气泡正文区域里

### 4. 鲸鱼位置避让

当前鲸鱼固定右下角，可能挡住目标矩形。

请实现简单的四角避让：

1. 默认右下
2. 如果目标矩形与鲸鱼窗重叠，尝试左下
3. 再尝试右上
4. 最后左上
5. 保持至少 20px 屏幕边距
6. 不覆盖目标矩形和箭头

不需要多显示器支持，当前单屏 2560×1440、150% 缩放。

### 5. 与主 overlay 的统一

主 overlay 已经有：

- 青色矩形
- 深色步骤标签
- 箭头

鲸鱼气泡不要和主标签重复显示同一句话。

建议：

- 主 overlay 保留目标矩形 + 箭头
- 鲸鱼气泡显示完整步骤 + 下一步
- 主标签可以缩短为关键词，例如“文件菜单”
- 或者主标签隐藏，只保留矩形/箭头 + 鲸鱼气泡

选择一种更干净的方案，不要两处都放长句。

### 6. 动效

保持轻量，不频繁打扰：

- 气泡出现：淡入 + 轻微上浮 4–6px
- 步骤切换：旧文字淡出/新文字淡入，或整窗轻微弹跳
- 按钮 hover：底色过渡
- 按钮按下：`scale 0.96` 或下移 1px
- 不要持续上下漂浮
- 不要每帧重绘整张鲸鱼图

音效保持现状：

- 点击“下一步”播放 `Ya1.mp3`
- 可关闭
- 播放失败必须静默降级
