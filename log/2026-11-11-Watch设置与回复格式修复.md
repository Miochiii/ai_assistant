# Watch 设置与回复格式修复（.10）

用户 B 站观看视频时出现“陪伴模型未返回有效回复”。代码中该消息唯一来自 parseModelReply 未得到 structured:true；截图显示已有 58 次采样、3 次请求和 1 次发言。能确定此次报错是回复格式校验拒绝，不能依据截图推断截图失败或 B 站限制。旧版没有保留原始失败文本，不能断言当时是普通文字还是坏 JSON。

修正提示词中非法的 true或false JSON 示例。完整、正常结束的普通文本回复也可输出；损坏 JSON、代码块等不直接显示，而增加格式跳过计数。格式失败与网络/模型调用失败分开，不因累计两次格式问题停止陪伴；原有工具调用、截断和取消检查保留。没有为了纠正格式追加第二次模型调用。提示词明确模型没有视频声音。

新增 companion-settings.js，读写项目 runtime/companion/settings.json，使用临时文件替换和串行保存，校验数字范围与布尔类型。设置不修改成熟记忆插件。

设置面板在现有 Orb 设置页中，沿用 React 与样式，独立读取 /.dsh-orb/companion-settings；GET/POST 均经过既有 Orb 身份校验。可设置采样秒数 1–10、看图秒数 10–180、发言秒数 0–300、主动陪伴开关和静默后降频。主动发言间隔内也暂停自动模型调用，不是付费生成后再丢弃。直接提问绕过自动节奏；关闭主动模式仍可本地采样，但只在提问时调用模型。

保存会暂停现有陪伴，保留短上下文，继续时读取新配置并重建采样定时器。少说一点/正常陪伴仍是当前轮临时快捷调整，持久默认以面板为准。

29 项相关回归通过；新增覆盖普通文本、坏 JSON 不中止、格式计数、范围校验、重读持久配置、仅提问模式、发言间隔控制模型请求，以及保存暂停/继续应用设置。更新保存生命周期测试后重跑 13 项陪伴测试通过。客户端/宿主 JS 语法检查通过。本轮未调用付费模型，未运行实际 DSH 设置界面或 B 站真实视频验收。

验收：重启 DSH；在设置的 Orb 开发版 · Mio 页面找到 Watch 卡片，保存参数，Orb 输入继续陪伴/开始陪伴，检查陪伴状态中的三个间隔。播放视频并插话，确认完整普通回复不再报格式错误。模型仍只看抽样画面，不能听见视频，也不保证读清缩略图小字。
