# 指导偏好第一阶段与面板接入

用户在面板输入“指导时使用：一次只说一步”，同一工作区的新会话收到“教我怎么用记事本”时，第一轮指导请求就会带上这个表达偏好。旧的“记住，以后教我一次只说一步”仍是仅保存，用户可再发一次启用命令。

## 给 DeepSeek 的面板接口

沿用已有的 `chat_submit` 用户事件。输入框和将来的菜单都可以提交同一命令。按钮点击应生成稳定的用户事件 ID，重发沿用原 ID。将设置入口放在用户主动操作的面板菜单里。模型建议和看屏输出走各自的显示通道。

| 用户操作 | 面板提交的文字 |
| --- | --- |
| 启用逐步指导 | `指导时使用：一次只说一步` |
| 更改为概览 | `指导时使用：先给概览` |
| 查看当前设置 | `查看指导偏好` |
| 停止自动使用 | `停用指导偏好` |

这四项均由本地宿主处理。“查看指导偏好”读取**当前设置**。要显示**某条回复实际携带的设置**，从 `PanelChatModel.complete()` 成功结果读取 `guidancePreference`（含 style、version）。指导请求使用默认表达时为 null，普通聊天省略此字段。下一阶段可在 `ResidentHost._runModel` 接受回复后，将它接到本地消息详情。不要在显示回复时重新查库推测，更不要把元数据拼回下一轮对话。角色卡负责声音、语气与称呼；指导偏好由宿主按场景组合。

## 作用范围与失效

- 当前支持“教我…”“请指导我…”和“指导：…”等显式入口。指导中的“下一步”“继续”等短追问沿用该场景，有活动指导任务时也支持这些追问。普通聊天与后台看屏均不会读取此设置。其他自然表达可使用“指导：”前缀。
- 记忆库通过用户和工作区定位固定键 `panel.guidance.style`。一条事务同时提交原始用户事件和新版本，以数据库提交顺序更新。重复投递当前事件幂等，旧事件不能覆盖新版本。每次指导按索引读取最新有效选择，只有专用用户渠道启用的两种样式能映射为固定格式提示。没有全库搜索、嵌入计算或额外模型调用。
- 面板按任务、场景和偏好版本决定是否复用四轮短历史。修改、停用、撤销或读库失败后，下次指导请求会丢开受影响的历史。普通聊天仍可引用看屏的最近一句发言。指导使用当前用户问题和已有活动任务的标题、步骤，不附加未标记来源版本的旧看屏旁白。若只说“继续”且历史已清空又无活动任务，模型提示会要求先澄清目标。
- 停用会保留版本记录；需要删除正文时走现有记忆删除计划与确认流程。对已发出的请求、已经显示的气泡以及用户重新输入的文字，设置变更不会追溯擦除。读库失败时，指导以默认风格继续，设置命令失败则明确向用户返回错误。

## 验收与下一步

临时 SQLite 集成测试覆盖仅保存、启用、跨会话与跨工作区、旧事件重投、更改、停用和原生撤销。另用本机 Harness 原生适配器和模拟网络响应检查最终请求体：旧风格和模拟模型对它的复述均未进入修改或撤销后的指导请求。主会话前后两轮请求仍与面板和看屏隔离。

复跑入口为 `tests/test_companion_memory.mjs`、`tests/test_assistant_panel_model.mjs` 和 `scripts/check_companion_isolation.mjs`。后者沿用上一份隔离日志的 Electron 离线运行方式。尚待真实面板验证模型是否按要求一次给出一步。后续面板可接上上述命令及回复详情，再单独设计用户确认后从自然聊天生成候选的流程。

2026-11-07 补充完成了文件通道入口验收，覆盖 `UiChannel → ResidentHost → PanelChatModel → SQLite`。使用真实的 `chat_submit` 事件启用和停用偏好，核对面板回执、指导任务步骤的传递，以及结束任务后的请求隔离。临时数据库和文件通道均在测试结束时清理。

当前可在重启 Harness 后用已有输入框验收，依次发送“指导时使用：一次只说一步”和“教我怎么修改记事本字体”。之后在同一工作区新开会话测试首次指导，再发送“指导时使用：先给概览”和“指导：重新介绍修改字体的流程”。最后用“停用指导偏好”及“查看指导偏好”检查停用回执。前面的离线测试验证了请求内容和状态变更；真实模型是否每次遵守表达要求仍需观察。
