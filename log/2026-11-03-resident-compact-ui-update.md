# 常驻助手紧凑界面改造

日期：2026-11-03。按用户提供的参考图调整呈现，不改变 Host 的事件协议与模型能力。

## 最终行为

- 常驻模式不再创建独立鲸鱼窗与大型白色历史面板。旧 Coach Overlay 和独立鲸鱼预览入口保持原样。
- 常驻输入条宽 560、高 64 物理像素：圆角、深蓝半透明、原生可输入控件；这不是系统背景模糊/Acrylic。
- 输入条上方为无背景透明文字层，加深色细描边以适应明暗桌面。消息层点击穿透、不激活；输入条正常接收焦点。
- 最多两条助手消息，每条最多显示两行，过长明确省略。新消息出现，上一条约 192ms 内上移并变浅，第三条消息到来淘汰最旧一条。这里“两条”按消息计，不按标点拆句。
- 最后一条新消息出现 12 秒后，消息层约 600ms 淡出；用户发送的正文不占助手浮动消息位置。
- 指导任务存在时在同一输入条内增加步骤与“检查下一步”/“跳过”；安静超时且未聚焦输入时也收起此行。重新输入或回看消息可恢复显示。
- “检查下一步”继续发送 `check_step`，不擅自推进；跳过继续发送 `skip_step`。是否进入指导由 Host 的 task 状态决定，未在 UI 用关键词伪造“教我”意图识别。
- `⋯` 菜单保留暂停/恢复观察、停止回答、结束任务、回看最近两条、步骤操作、关闭助手；左侧点阵区域可拖动位置。
- 消息消失仅改变显示，不删除通道中已有记录，也不关闭 Host 或观察服务。

## 文件

- 修改 `tools/coach_overlay/resident_panel.py`：沿用现有 channel，替换大面板与常驻鲸鱼的呈现。
- 新增 `tools/coach_overlay/resident_compact.py`：输入条、透明消息层、动效、收起、指导控件。
- 新增 `tools/coach_overlay/test_resident_compact.py`：fake channel 的 Tk 回归与 35 秒自动退出预览。

没有修改 Node Host、实际模型调用、动作执行器或记忆库。新模块与 resident_panel.py 同目录，已有启动路径可继续使用；运行中的旧 UI 需关闭后重新打开，才能加载新代码。

## 验证

- Python 3.12 本地 Tk 两项回归通过：消息上限/到期隐藏/长文本、输入与步骤控制的事件兼容性。
- Node 协议、通道、生命周期 16 项回归通过。默认隔离启动被沙箱 `spawn EPERM` 阻止，使用 `--test-isolation=none` 执行通过。
- 使用假消息在实际桌面短时预览，截图检查了透明消息、旧消息变浅、深蓝圆角输入条；未请求模型、未截图发给第三方服务、未操作目标软件。
