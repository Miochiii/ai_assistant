# 桌面启动配方与记忆作用域修复

更新日期：2026-11-13。承接《2026-11-12-新开发主线-手机远控文字操作与精准点击.md》的 P0/P3 部分：本文件只记录**已实测通过**的启动能力、记忆作用域的坑，以及还没验证的东西。点击精度按用户判断暂停推进（"模型多看两眼就能点对"），本文件不涉及。

## 1. 结论先说

- **六个常用应用全部可以一句话启动**（iKuuuVPN / 微信 / PyCharm / VS Code / QQ / ChatGPT），配方见 §2。
- **"codex"就是 ChatGPT**：开始菜单悬停显示 ChatGPT，包名是 Codex，进程名 `ChatGPT`。按名字搜 codex 永远搜不到。
- **启动必须绕 explorer**：直接 `Start-Process <exe>` 起来的进程会随 pwsh 作业被连坐杀掉。
- **记忆作用域是上次"Orb 查不到启动记忆"的真正原因**：写进 project 轨的记忆按 cwd 隔离，Orb 的 cwd 是 `dsh_orb_work`，看不到本工作区的 project 轨。机器级事实必须写 **全局轨（target=memory）**。
- **端口重新分配**：8000 留给 RAG，ASR 挪到 8100。

## 2. 启动配方（本机，2026-11-13 实测）

统一姿势（绕开作业连坐）：

```powershell
Start-Process explorer.exe -ArgumentList '"<绝对路径>"'
```

AppID 形式的用 `shell:AppsFolder\<AppID>`：

| 应用 | 路径 / AppID | 备注 |
|---|---|---|
| iKuuuVPN | `E:\vpn\ikuuu_vpn\iKuuuVPN.exe` | 起来后还要点连接，见 §3 |
| 微信 | `D:\Weixin\Weixin.exe` | 先查进程再启 |
| PyCharm | `E:\pycharm\PyCharm 2025.1.1.1\bin\pycharm64.exe` | 先出 splash，窗口要等几秒 |
| VS Code | `E:\vscode\Microsoft VS Code\Code.exe` | 会恢复上次会话 |
| QQ | AppID `QQ` → `shell:AppsFolder\QQ` | 先查进程，重复启动会弹登录窗 |
| ChatGPT（=codex） | AppID `OpenAI.Codex_2p2nqsd0c76g0!App` | 进程名 ChatGPT，窗口内标题栏写 Codex |

启动后验收：`Get-Process <名字> | Select ProcessName,Id,MainWindowTitle`，标题非空才算窗口出来了。

## 3. iKuuuVPN 的连接动作

1. 启动后等 ~8 秒，`ShowWindow(hwnd, 9)` + `SetForegroundWindow` 置前，`GetWindowRect` 取矩形；
2. 在 **55% 宽、30% 高** 处点一下圆形按钮（悬停"点击连接"→ 点后变暂停图标）；
   - 实测 750×600 的窗口 → 点击点 (914, 431)；
3. 判定已连接（不能只看进程）：
   - 窗口里出现"已连接"和计时器（实测计时 00:00:22）；
   - `Invoke-WebRequest https://www.google.com -Method Head` 从 FAIL 变 **200**；
4. 连上后再启动 ChatGPT/Codex。

规则模式下国内站点照常走直连，所以**只有墙外站点的 200 是有效信号**。

## 4. 记忆作用域的坑（这次的主要修复）

现象：用户让 Orb 启动 codex，Orb 说"查不到任何相关记忆"。

- 我之前把配方写进了 **project 轨**（`runtime/memory-evolve/projects/<hash>/MEMORY.md`），这个轨**按 cwd 隔离**；
- 本会话 cwd = `E:\file\agent\ai assistant`，Orb 会话 cwd = `dsh_orb_work`，两个 project，互相看不见；
- 修法：机器级事实改写进 **全局轨**（`memory(action='add', target='memory', ...)`），它在任何 cwd 都会注入；
  已写入三条：启动配方、VPN 连接流程、端口分配。

写记忆一律用 memory-evolve 的 `memory` 工具（`target=memory|user|project|key|daily`），不要手改 MEMORY.md。
